Functions defining from Raisha paper (Lovindeer et al. in prep)

Equation 10

M_contam_daily <- function(C_bio, LC50, beta_LC){
  return(log(1+(C_bio/LC50)^beta_LC))
}

Equation 11

k_growth <- function(C_bio, EC50, beta_EC){
  return(1/(1+C_bio/EC50)^beta_EC)
}

Equation 12

k_growth2 <- function(C_bio, k, c_range, c_mid){
  return(1-k/(1+exp(c_range*(c_mid-C_bio))))
}

Equation 13

k_repro <- function(C_bio, w_r, c_chronic){
  return(1-(w_r*(C_bio-c_chronic)))
}

Mortality

The equation is M_contam (/day) in function of the concentration in the organism (Cbio). Our data is the % of mortality on an experiment. We need to convert our data into a rate. A first simple assumption is to divide the relationship by the average exposure time (88 d)? N(t) = N(0) * e^(-Zt)

N(t) = % reduction N(0) = 1 (initial condition: 0% reduction) t = 88days (average time of the experiments)

log(N(t)) = log(N(0) * e^(-Zt)) log(N(t)) = log(N(0)) + log(e^(-Zt)) log(N(t)) = -Zt Z = -log(N(t))/t

Simple temporal assumption

for (i in 1:length(data_PCB118$Species)){
  dataset.sp <- dataset
  dataset.sp$concentration_PCB118 <- dataset.sp$Concentration*data_PCB118$Contrib_of_tot[i]
  # Growth
  mod.growth <- nls(dataset.sp$growth~k_growth(dataset.sp$concentration_PCB118, EC50, beta_EC), 
                    data = dataset.sp, 
                    start = c(EC50 = 0.02216*data_PCB118$Contrib_of_tot[i],   beta_EC=0.04786))

    # Repro
  mod.repro <- nls(dataset.sp$reproduction~k_growth(dataset.sp$concentration_PCB118, EC50, beta_EC),
                   data = dataset.sp, 
                   start = c(EC50 = 0.000426951*data_PCB118$Contrib_of_tot[i], beta_EC=0.07679039))
  
  
  # Mortality
  dataset.sp$daily_mort_rate <- -log((1-dataset$mortality))/88
  dataset_contam.sp <- dataset.sp[dataset.sp$daily_mort_rate!=Inf,]

  mod.mortality <- nls(dataset_contam.sp$daily_mort_rate~M_contam_daily(dataset_contam.sp$concentration_PCB118, LC50, beta_LC), 
                       data = dataset_contam.sp, 
                       start = c(LC50 = 2.713e+07*data_PCB118$Contrib_of_tot[i], beta_LC=3.719e-01 ))
  

  # Save results
